# Wanderly — Travel Website

A professional responsive travel website built for a frontend portfolio using **React.js, JavaScript, HTML5 and CSS3**.

## Features
- Responsive navbar with mobile menu
- Hero section with destination search
- Destination filtering
- Popular destination cards
- Tour packages with pricing and inclusions
- Interactive booking request form
- About Us and Contact Us sections
- Responsive footer
- Reusable React UI patterns and state management
- Mobile, tablet and desktop layouts

## Tech Stack
React 18 · JavaScript ES6+ · HTML5 · CSS3 · Vite · Lucide React

## Project Structure
```text
src/
├── App.jsx
├── main.jsx
└── index.css
```

The repository originally contained a TypeScript/Tailwind starter and existing travel components. Those files were inspected and retained; the new JavaScript implementation is the active Vite entry point.

## Run locally
```bash
git clone https://github.com/punambala/Travels-website.git
cd Travels-website
npm install
npm run dev
```

For a production build:
```bash
npm run build
npm run preview
```

## Portfolio highlights
This project demonstrates component-oriented React development, hooks/state, search filtering, controlled forms, responsive CSS, semantic HTML and polished UI design.

> Booking and contact submissions are frontend demo interactions; no real backend or payment processing is connected.
